## 👨‍💻 About Me

I'm **Tomide Adeyanju**, a Frontend Engineer with a strong interest in Accessibility Engineering and building inclusive digital products.

I enjoy translating complex ideas into intuitive user interfaces, developing scalable frontend applications, and ensuring that digital experiences are accessible to everyone.

My work combines modern frontend development with accessibility testing, usability, and performance optimization.

- 💻 Working primarily with **React, TypeScript, JavaScript and Next.js**.
- ♿ Interested in **Web Accessibility, WCAG 2.2 AA and Section 508 compliance**.
- 🧪 Experienced with manual accessibility testing, keyboard navigation and assistive technologies.
- ☁️ Exploring cloud technologies, AI-powered applications and modern web architectures.
- 📚 Currently pursuing an MSc in Information Technology.
- 🎯 Always interested in building products that solve real-world problems.
